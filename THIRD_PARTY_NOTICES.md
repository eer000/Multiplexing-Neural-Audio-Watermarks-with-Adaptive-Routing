# Third-party components

The model bundle uses components derived from [AlignMark](https://huggingface.co/haiyunli/AlignMark) by Haiyun Li, Shuhai Peng, Zhisheng Zhang, Jingran Xie, Xiaofeng Xie, Hanyang Peng and Zhiyong Wu, and [SpeechTokenizer](https://github.com/ZhangXInFD/SpeechTokenizer) by Xin Zhang, Dong Zhang, Shimin Li, Yaqian Zhou and Xipeng Qiu. Their released code is distributed under Apache License 2.0, included in [licenses/Apache-2.0.txt](licenses/Apache-2.0.txt).

The presence readout, length-dependent encoder padding, embedding integration, fixed-query presence interface and evaluation entry point are additions or modifications to these components. The bundle retains component attribution and source provenance.
